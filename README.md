### General ideas about the game

Large destructible skyscraper base that you need to defend (upgrade defences) against hordes of various monsters.
Destruction from The Finals + Project Zomboid survival + Megabonk addictive upgrades cycle.
But not one-run game, more of a gradual progress and collecting items, combining, updating, improving the number of waves you can survive.
Drop huge buildings on hordes of monsters.

### Running examples

```bash
RUST_BACKTRACE=1 MTL_HUD_ENABLED=1 cargo run --example <EXAMPLE_NAME> --features bevy/dynamic_linking
```
